V0.5 游戏性审计的脚本。在本目录下 `node e1_stat.js` 这样跑，读的是项目里的 src/ 和 data/。
e1 属性、e2/e2b 装备槽和宝物、e3 档内单人与技能值、e4 统一尺子、e5 档差/星级/装备、e6 战力数字准不准、e7 残兵持平点、e8 专属、e9 输了回满。
check_text.py 列出技能文案和实际数值对不上的条目。
V0.6 规范用的：e10_agi.js / e11.js 测速度接暴击闪避的几组参数（要先把 SG.AGI 接进引擎才有效）；pt_e.js 是一周目模拟加了战败规则的变体，`CANBING=1 VAR=E node pt_e.js 24` 是「输了退回出战前」，VAR=D 是现在的「输了回满」，VAR=X 是「输了也只回两成」，AGI=1 打开速度规则。
